A travel poster for VELMORA — a place that isn't there. Golden hour over a turquoise lagoon, with the Lantern Spire standing on its needle rock, an arched bridge to the shore, and the name set large in cream across the dusk sky. Drawn procedurally in Python + Pillow: no photos, no network, no external assets. The only text in the image is the place name, VELMORA.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png`. Deterministic: run it twice and the bytes are identical.
